🔧 Falta conectar la base de datos (una sola vez)

El chat ya está programado; solo falta la llave gratuita de Firebase. Pásasela a tu admin (o hazlo tú en 5 minutos):

  1. Entra en console.firebase.google.com → Crear proyecto (nombre road-to-trillon, sin Analytics).
  2. Compilación → Realtime Database → Crear base de datos → ubicación europea → modo bloqueado.
  3. Pestaña Reglas y pega esto: 
    {
  "rules": {
    "messages": {
      ".read": true,
      ".write": "auth != null",
      "$m": {
        ".validate": "newData.hasChildren(['nick','text','ts']) && newData.child('text').val().length <= 300"
      }
    }
  }
}
  4. Compilación → Authentication → Comenzar → Anonymous → Habilitar.
  5. Rueda de Configuración del proyecto → Tus apps → web (</>) → copia el objeto firebaseConfig y envíaselo a tu admin.
